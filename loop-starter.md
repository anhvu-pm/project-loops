# My first Project Loop

Choose one recurring decision or update. Fill in the brackets, then give the brief and your project notes to your agent.

## Plan
- Output and audience: [e.g. a Friday release decision for the sponsor]
- Decision needed by: [date]
- Source notes: [paste the latest facts and open questions]
- Done when: [e.g. the sponsor can see the decision, owner and deadline]

## Do
Draft the update from my notes. Lead with the decision needed. Mark missing facts as questions and distinguish scheduled reviews from approvals.

## Learn
Compare the draft with the notes. Check each owner, date and approval. What did the first draft miss?

## Act
Revise the draft and review it before sharing. Save one instruction that would catch the same miss next week. Replace the notes and run the Loop again.
